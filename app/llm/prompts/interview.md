# 작업: 부족 정보 인터뷰 질문 생성

<참고자료>에는 공고문, 사업계획서 양식(섹션·작성 지시문), 평가표가 있다.
사용자 메시지에는 현재 보유한 기업·아이템·성능지표·선행연구 정보와 이미 답변된 질문이 있다.

각 섹션의 작성 지시문과 평가항목을 충족하는 데 **부족한 정보**만 골라 질문 목록을 만든다.
- 이미 제공된 정보는 다시 묻지 않는다.
- 질문은 답하기 쉽게 구체적으로(예: "목표 에너지 절감률(%)과 측정 방법, 시험기관은?").
- 정량 수치·출처가 필요한 곳(시장규모, 사회적 비용 통계, 성능지표, 매출 계획)을 우선한다.
- 섹션당 최대 4개, 전체 최대 20개.

출력(JSON만):
```json
{"questions": [{"section_key": "s1", "question": "...", "why": "평가항목 '기술개발 목표의 구체성' 대응"}]}
```
